# History of the F=68 publication

## Original result

On July 22, 2026, the project publicly recorded

$$
F(6{,}148{,}888{,}817)=68
$$

with terminal prime $9{,}500{,}401$. The original public Git tree contained a README, a minimal SymPy verifier, citation metadata, an MIT license, and an AI-use disclosure.

The accessible historical commit is:

```text
905b682406251e98c9a2d1569a8a67ae82910a0e
```

Its tree was:

```text
3fbb30d9ede96e07e88b463654ce1e7c21afb88d
```

## Repository migration

The original repository was later renamed and repurposed for Erdős Problem #64. A separate correctly named Problem #409 repository was then created. An initial automated migration overemphasized the $F=68$ witness and introduced unsigned API commits.

The corrected publication treats $F=68$ as the historical base of a broader #409 research archive and extends it through certified $F=69,70,71$ witnesses.

## Preservation principle

Historical claims are preserved without silently converting them into current claims. In particular, a statement that $F=68$ was the largest known value at the time of the July publication is historical provenance, not an assertion about the literature at every later date.
