# Claims and scope

For `T(n)=phi(n)+1`, let `F(n)` be the first index at which the iterated
trajectory reaches a prime. The F=104 packet certifies

```text
F(400000287233629) = 104
terminal prime = 27515203921
trajectory nodes = 105
trajectory SHA-256 = 3faf8aa1b74ffa39d8e72b45b0a57ceffbc631a958f7a8bed758d3caaa745394
```

Therefore it establishes only the general lower bound

```text
sup_n F(n) >= 104.
```

It does not establish that 104 is a world record or global maximum,
unboundedness of `F`, infinitely many members of a terminal-prime basin,
positive density, inverse-tree completeness for the F=104 witness, or a
solution of any global part of Erdős Problem #409. Priority is not claimed.

The separate rooted inverse-tree result in this repository applies only to the
earlier F=68–71 chain in its expressly stated local scope.
